# Traps

Two traps that lie on a ground tile: **caltrops** and a **bear trap**. Each has a **placed** sprite (the trap waiting, one frame) and a **triggered**
animation (what happens when something steps on it). Everything for them is in this folder and shares the `trap-` prefix. On the Assets page it is the **Traps** category.

| File | What it is |
|---|---|
| `trap-caltrops.png` | Caltrops, placed: five iron jacks scattered on the ground. One frame |
| `trap-caltrops-triggered.png` | Caltrops, triggered: 6 frames. They flash, hop, tumble in a ring of dust and land spread wider |
| `trap-beartrap.png` | Bear trap, placed: open, toothed jaws lying round a pressure pan, with a short chain. One frame |
| `trap-beartrap-triggered.png` | Bear trap, triggered: 6 frames. The pan drops, the jaws swing up and snap shut, and it rests closed |
| `traps.json` | Every file above, the frame names, the anchor and the frame rate, for the app to read |

Each sheet is one row of **32 x 32** frames, in the shared palette's colour roles, so it recolours with the rest of the game.

## Placing one

Draw the sprite with its **anchor on the middle of the ground tile**, the same point a character stands on. The anchor is **(16, 24)** in the 32 x 32 frame:

```js
const gx = mapOffsetX + 16 * (x - y), gy = mapOffsetY + 8 * (x + y);          // the ground tile's top left, as in the buildings README
ctx.drawImage(sheet, frame * 32, 0, 32, 32, gx + 16 - 16, gy + 8 - 24, 32, 32);   // the anchor (16, 24) on the tile's middle (16, 8)
```

A trap is a flat thing on the ground, so draw it **above the ground and under anything that stands on that tile**: before the characters, after the ground. It is one picture for every
facing (it is drawn from the SE camera and looks the same either way round).

## The triggered animation

- Swap the **placed** sprite for the **triggered** sheet at the moment the trap goes off.
- Play it **once** at **10 frames a second** (`traps.json` > `fps`) and **hold the last frame**. It does not loop.
- The last frame is the trap **spent**: the caltrops lie scattered wider than they were, and the bear trap is clamped shut. Keep drawing that frame for as long as the trap stays on the map, or remove the trap.
- Both sheets share the same size and anchor, so the swap does not move anything.
- The frames, in order. Caltrops: stepped on, pop, tumble, fall, land, rest. Bear trap: pressed, jaws lift, swing, closing, snap, shut.

## Rebuilding these files

```bash
python3 tools/make_assets.py --png-dir sprites/assets          # writes this whole folder, and the Traps category on the Assets page
python3 tools/make_traps.py --model previews/traps-3d.png --preview previews/traps.png    # the 3D models, and the sprites enlarged
```

The sheets are generated by code (small 3D models of ellipsoids, as for the vine spell), so change `tools/make_traps.py` and rebuild instead of editing the PNGs.
